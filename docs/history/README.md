# Archived decision logs

These are the unchanged audit logs committed by each milestone's own demo run,
kept here when the branches were integrated so that no history was lost or merged
into an invented combined execution.

- `milestone2_decision_log.json`: Milestone 2 Discover runs (branch `fix/milestone2-evidence-quality`, commit `ac7afd5`).
- `milestone3_decision_log.json`: Milestone 3 Builder demo (branch `feature/milestone3-builder`, commit `b2a2f26`).

The root `decision_log.json` holds the log of the integrated application's own runs.
