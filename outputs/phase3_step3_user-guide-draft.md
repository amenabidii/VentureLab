# Phase 3, step 3: User guide (DRAFT)

> DRAFT for the founder to complete once the MVP exists. The MVP's code is STUBBED; this guide
> describes the intended core job, not delivered features.

## What it is for

remote engineers and product managers on distributed teams: Remote workers waste time catching up on long Slack threads they missed.

## Intended core job

A browser extension that summarises long Slack threads a remote team member missed, linking each point back to the original message.

## Getting started (intended)

1. Install or open the product.
2. Do the core job once on your own material.
3. Check every result against its original source before relying on it.

## Limits

- Results can be wrong; the original source is always the reference.
- Constraints honoured: Value: Respect privacy, no dark patterns; Constraint: Messages are only read in workspaces that install the extension.
