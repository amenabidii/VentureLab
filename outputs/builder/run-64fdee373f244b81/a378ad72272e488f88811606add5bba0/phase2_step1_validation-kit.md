## Customer Interview Guide

Situation to listen for: Remote workers waste time catching up on long Slack threads they missed.. Questions say "this situation" so the participant describes it in their own words; name it neutrally if they ask. Do not describe or show the proposed solution until every question has been answered. A participant with no recent occurrence is a valid result, not a failed interview.

1. Tell me about the last time, if any, you encountered this situation. What happened?
2. What steps did you take to address it that time?
3. Which tools or alternatives did you use, and how did they fit your process?
4. What time or effort did that experience require?
5. What, if anything, was difficult about your existing approach?
6. When did this last occur before that occasion?
7. What, if anything, have you already tried to change about this process?

PROPOSED ASSUMPTION — requires founder approval: at least 3 of 5 participants. Participants describing a concrete instance within the proposed 30-day recall window and an action they took.
